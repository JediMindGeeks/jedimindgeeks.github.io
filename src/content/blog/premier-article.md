Bienvenue sur **JediMindGeeks** !

Ce site est mon espace personnel où je partage mes projets, mes apprentissages et mes réflexions sur le développement logiciel.

## Ce que vous trouverez ici

- **Des articles techniques** sur le développement web, les bonnes pratiques et les outils que j'utilise
- **Des projets** que j'ai réalisés ou sur lesquels je travaille
- **Des retours d'expérience** sur les technologies que j'explore

## La stack technique

Ce site est construit avec [Astro](https://astro.build), un framework moderne qui génère des pages HTML statiques ultra-légères. Il est hébergé gratuitement sur [Cloudflare Pages](https://pages.cloudflare.com) avec un CDN mondial.

```bash
# Pour lancer le site en local
npm install
npm run dev
```
