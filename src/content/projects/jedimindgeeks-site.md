## Présentation

Site personnel servant de portfolio et de blog technique. Conçu pour être rapide, accessible et facile à maintenir.

## Fonctionnalités

- Blog avec support Markdown et MDX
- Système de tags avec archives
- Flux RSS
- Sitemap automatique
- Design responsive
- Score Lighthouse optimal

## Stack technique

- **Astro 4** — Génération de site statique, zéro JS par défaut
- **SCSS** — Styles modulaires avec variables CSS
- **TypeScript** — Typage strict sur toute la codebase
- **Cloudflare Pages** — Hébergement gratuit avec CDN mondial

## Architecture

Le site utilise le système de **Content Collections** d'Astro pour gérer les articles de blog et les projets. Chaque contenu est typé via Zod pour éviter les erreurs à la compilation.
